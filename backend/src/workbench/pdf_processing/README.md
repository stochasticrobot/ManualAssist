# Pdf Processing

Read original PDFs into text, tables, pictures and page-linked navigation.

These files make manual content available for searching, citation and display.
Reading a document does not establish that its instructions are complete or safe.

## Files

| File | What it does |
| --- | --- |
| [build_contents_page_links.py](build_contents_page_links.py) | Make the manual's table of contents open the correct pages in the PDF viewer. |
| [inspect_parsed_sources.py](inspect_parsed_sources.py) | Carry out the closer looks requested by the retired manual-preview process. |
| [normalize_parsed_pdf.py](normalize_parsed_pdf.py) | Organize extracted PDF text, tables and pictures into page-linked records. |
| [parse_and_save_pdf.py](parse_and_save_pdf.py) | Read an uploaded PDF locally and save the text and layout the application will use. |
| [validate_and_render_pdf.py](validate_and_render_pdf.py) | Check uploaded PDFs and turn selected original pages into viewable images. |
