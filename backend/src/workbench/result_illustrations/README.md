# Result Illustrations

Show suitable original manual pictures alongside saved results.

The pictures help identify the product and its parts. They remain reference
illustrations, not AI-generated instructions or proof that a repair is safe.

## Files

| File | What it does |
| --- | --- |
| [assess_static_illustration.py](assess_static_illustration.py) | Decide whether a manual image is suitable as a general reference illustration. |
| [prepare_source_illustrations.py](prepare_source_illustrations.py) | Prepare selected original manual pictures for the Results pages. |
