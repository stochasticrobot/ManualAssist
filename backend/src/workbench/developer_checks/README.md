# Developer Checks

Provide explicit developer checks of configured AI connections.

These commands help diagnose connection and basic response problems without
starting a manual analysis. Live checks must be requested and may incur charges.

## Files

| File | What it does |
| --- | --- |
| [check_live_model_connection.py](check_live_model_connection.py) | Check whether the configured text and image models can answer simple requests. |
