# Job Storage

Keep uploaded manuals and their work records separate and recoverable.

Each manual has saved source files, progress, model requests and generated output
so the browser can reopen results and interrupted analysis can continue.

## Files

| File | What it does |
| --- | --- |
| [job_files_and_audit_log.py](job_files_and_audit_log.py) | Save each uploaded manual, its progress, results and history in its own folder. |
