# Workbench

Provide the Python application that turns PDF manuals into searchable facts and
practical guides.

The package contains document reading, AI-assisted analysis, saved results and the
local web interface. Importing this package alone does not process a manual.

## Files

| File | What it does |
| --- | --- |
| [app.py](app.py) | Provide the application address used by the server's launch command. |
| [config.py](config.py) | Locate the project folder and browser files relative to the installed Python code. |
