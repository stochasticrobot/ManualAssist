# Mk II Laser Blaster sample manual

[Download the four-page PDF](manual.pdf), then upload it using the application's
normal file picker. Configure model access first; analysis makes live provider calls.

This original fictional manual describes the MK2-T Academy training blaster, which
registers simulated pulses on holographic targets. It is not a real weapon design.
It includes unpacking and installation, sealed battery replacement, a manual safety,
low-power and human-contact interlocks, cleaning and storage, and five diagnostic
conditions with remedies and completion checks.
